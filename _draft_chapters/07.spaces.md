 The triangle inequality for metric spaces states the following:

If you have some two points, 'a' and 'b', then the distance between them ('ab')  would be either equal or shorter than  the combined distances between those two and any third point: ('ab' ≤ 'az + zb' for any 'z'). 

In particular, it will be equal, if 'z' is a point in 'ab'. And if it is not, then the three points form a triangle.

All this is trivial, becomes more interesting when you realize that vector spaces are topological spaces, so there must be something like this law for all topological spaces.

General topological spaces don't have the concept of distance, but they have the concept of meets/joins.

If you have some two objects, 'a' and 'b', then their join ('a x b')  would be either equal or 'lower' in the order, than the combined joins of those two objects and a third, so ('a x b' ≤ '(a x z) x (z x b)' for any 'z'). 

In particular, it will be equal if z is at the same level as 'a' and 'b'.
